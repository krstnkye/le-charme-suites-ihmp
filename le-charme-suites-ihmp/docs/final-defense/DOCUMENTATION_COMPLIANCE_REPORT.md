## 3. Template documentation rules

| Rule | How it was met |
|---|---|
| One documentation file per team | One file. |
| Every major feature explained and supported by evidence | Each module in 4.6.2 has a screenshot, and is linked to test cases in Table 14 and the traceability matrix in Table 19. |
| Screenshots show the actual system, labelled and referred to in text | 44 numbered figures and 28 numbered tables. All screenshots come from the running build. Every figure and table is referred to in the text by its number. |
| Do not paste all source code in the body | Only short excerpts, in Appendix A. The full code is in the repository. |
| Acknowledge borrowed code, libraries, frameworks and APIs | Table 3 and the references list every framework and library used. |
| Consistent naming | Role names, table names and screen labels match the code. The cashier role is called "Billing" on screen, and this is explained once in Table 1. |
| Record actual test results | Test results come from runs on 7 Nov 2026. Illustrative values (for example truncated tokens in API examples) are labelled as such. |

## 4. Deviations and decisions to note

1. **Instruction pages removed.** "How to Use This Template" and "Documentation Rules" were removed on the team's instruction.
2. **Citation style.** The template does not name one, so APA 7th edition was used. The team should confirm the instructor accepts this.
3. **Captions added.** The template has no figure or table captions. "Figure N." and "Table N." captions were added because the rules require labelled figures.
4. **Smaller font in wide tables.** Tables with five to seven columns use 9–11 pt so they fit the page. Body text stays 12 pt.
5. **Body alignment.** Body text is left-aligned, matching the template's Normal style.
6. **No List of Figures or List of Tables.** The template does not include them, so none were added. They can be inserted in Word (References → Insert Table of Figures) if the instructor asks.
7. **Extra figures and tables.** Some diagrams (use case, ERD, state diagram, deployment) and supporting tables (branch status, troubleshooting, CV checklist) were added inside the template's sections. No new chapters were created.
